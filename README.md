# E-Commerce Analytics Dashboard

##  Project Overview

This is a comprehensive data analytics project that analyzes e-commerce sales, customer behavior, and operational metrics.

**Stack:**
- Python (Pandas, NumPy, SQLAlchemy)
- SQL (PostgreSQL)
- Power BI
- GitHub

##  Data Format

Data is available in Excel format:
- **File**: `data/ecommerce_data.xlsx`
- **Sheets**: 4 (Customers, Products, Orders, Order Items)
- **Total Records**: 7,460 rows
- **Format**: Excel (.xlsx)

### To use with Power BI:
1. Open Power BI Desktop
2. Get Data → Excel workbook
3. Select `data/ecommerce_data.xlsx`
4. Load all 4 sheets
5. Create visualizations

##  Project Goals

1. Collect and clean e-commerce data
2. Store data in SQL database
3. Perform complex SQL analysis
4. Create interactive Power BI dashboard
5. Generate actionable insights

##  Folder Structure

- `data/` - Raw and processed data
- `src/` - Python scripts
- `sql/` - SQL queries and schema
- `notebooks/` - Data analysis notebooks
- `powerbi/` - Power BI dashboard file
- `docs/` - Documentation
